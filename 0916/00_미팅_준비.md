## 2. 사수가 9/2에 시킨 것 → 답

### 몫 1. Persona — "PHQ-8 + demographics보다 나은 주입 특징이 있나"

**있습니다. 다만 방향이 예상과 달랐습니다 — 척도를 바꾸는 게 아니라 블록을 추가하는 것입니다.**

| 사수가 물은 것 | 답 |
|---|---|
| BDI-II로 바꿀까 (TalkDep 방식) | **아니오, PHQ-8 유지.** BDI-II로 세우면 DAIC 라벨과 척도가 달라 **역채점 게이트를 못 겁니다.** TalkDep의 "핵심증상 최대 4개" 제한도 DAIC 양성의 **45.2%**만 해당해 그대로는 못 씁니다 |
| 더 나은 특징은 | **① Ellie가 안 묻는 항목을 빼기** — PHQ-8 8개 중 **4개(Appetite·Tired·Concentrating·Moving)는 Ellie 질문 87개에 대응이 없습니다.** 주입해도 대화에 나올 자리가 없습니다<br>**② 대화를 분기시키는 사실을 넣기** — 자녀·치료경험·진단·이주·군복무. 현행 persona에도 라벨에도 없는데 **대화 흐름을 실제로 바꿉니다** |
| 몇 개를 만들까 | **고정 집합은 안 맞습니다.** 양성 42명이 **고유 조합 30가지**. train 107명의 **라벨 벡터를 골격으로** 쓰고, 여기에 스타일 6종을 직교로 얹어 배수를 만듭니다 |

제안 스키마는 5블록(증상·분기·전기·일화·스타일) + 게이트 5종 → `01_persona_조사.md` §3.

### 몫 2. SER — "SER 사전학습 모델이 적합한가, 어떤 모델인가"

**Q1. SER용이 ASR용보다 나은가 → 네.** (사수 가설 성립)

| embedding | test AUC |
|---|---:|
| 기존 whisper encoder (ASR용, 0821 표) | 0.626 |
| **emotion2vec+ (SER용)** | **0.671** |

9/9에 **결과 보기 전에** 게이트를 "test AUC 0.626 초과"로 지정했고 통과했습니다.

**Q2. 어떤 모델인가 → emotion2vec+.**
동일 턴·동일 잣대(cv189) 비교에서 Emotion2Vec-S(0.580)보다 **0.664로 앞섭니다.**
단 신뢰구간이 0을 포함해(−0.084 [−0.179, +0.011]) **확정은 못 합니다.**

**Q3(사수가 묻지 않았지만 핵심). 그래서 성능이 올랐나 → 측정 불가.**
기존 최고 시스템에 얹었을 때 **dev +0.123 / test −0.039로 두 평가셋이 정반대**이고,
paired bootstrap 8개 비교 **전부 신뢰구간이 0을 포함**합니다.
**"기여 없음"이 아니라 "기여를 확인할 수 없음"** — 이 구분이 이번 보고의 핵심입니다.

## 4. 사수 판단이 필요한 것 — 5건 (우선순위 순)

| # | 안건 | 왜 사수 판단인가 | 내 의견 |
|---|---|---|---|
| **1** | **augmentation 목표를 "측정 가능성 확보"로 재정의할지.** 목표 화자 수 **210명(간신히) ~ 860명(여유)** | 프로젝트 전체 방향. 이걸 정해야 나머지 4건이 따라옴 | **찬성.** "데이터가 적어서 성능이 안 나온다"보다 **"화자가 적어서 개선 여부를 측정할 수 없다"**가 논문에서 훨씬 강한 논거 |
| **2** | **분기-라벨 상관을 재현할지.** 치료 경험이 **양성 75.0% vs 대조 25.4%** | 증강 데이터의 유효성이 걸림 | 재현하면 분류기가 **증상이 아니라 "치료 얘기가 나왔는가"를 학습**할 수 있음. 독립 샘플링하면 실제 단서가 빠짐. **양쪽 다 만들어 비교**하는 게 안전 |
| **3** | **speech 가지를 화자 수 확보 전까지 보류할지** | 리소스 배분 | **보류 쪽.** 무엇을 만들어도 지금 평가셋으로는 증명이 원리적으로 불가. 단 **timing 계열은 예외**(§5) |
| **4** | **Emotion2Vec-S를 원설계대로 재시도할지** — 10토큰을 평균하지 않고 오디오-LLM 인코더로 | 비용 대비 가치 판단 | 우리 평균 방식만으로 S를 기각하기엔 근거가 약함. 다만 **1번이 정해지기 전엔 순위 낮음** |
| **5** | **0821 산출물·코드 소재** | 사수만 앎 | 화자별 text 점수 파일이 없어 융합 기준선을 응답 지연으로 **대체**했음. 원본이 있으면 정식으로 다시 잼 |

## 5. 예상 질문 대비

**Q. "그래서 SER 쓸 만한 건가?"**
→ 모델 선택은 끝났습니다(emotion2vec+). **쓸 만한지는 이 데이터로 판정이 안 됩니다.**
화자 210명이 넘어가는 순간 판정 가능합니다. 지금 코드는 그대로 재사용됩니다.

**Q. "+0.081이면 오른 거 아닌가?"**
→ 신뢰구간 반폭이 **±0.085**입니다. 간발의 차로 미달입니다.
직관적으로: test 47명은 양성 14 × 음성 33 = **462쌍**이라 **한 사람 순위가 바뀌면 AUC가 0.03~0.07 움직입니다.**
"+0.03 개선"은 곧 "한 명이 자리를 바꿨다"는 뜻입니다.

**Q. "0821 표에서 speech가 도움 됐다고 하지 않았나?"**
→ 0821의 "latency가 test AUC를 +0.01~0.03 올린다"는 **이 잡음 범위 안**입니다.
해당 수치는 재해석이 필요합니다. 이건 제 쪽 결과가 아니라 **기존 표에 대한 정정 제안**입니다.

**Q. "그럼 speech는 버리나?"**
→ 아니오. **세 번의 독립 시험에서 살아남은 것은 전부 시간 구조입니다.**
`lat_symptom_vs_neutral`(증상 질문에 더 뜸들이는 정도) **0.650**,
반면 `neg_symptom_vs_neutral`(증상 질문에서 감정 변화) **0.512 = 무용**.
**"증상 질문을 받으면 감정이 달라지는 정도"에는 개인차가 없고,
"대답이 늦어지는 정도"에는 개인차가 있습니다.**

**Q. "감정 feature 중에 건진 건 없나?"**
→ 하나 있습니다. `neg_p90_minus_p50`(부정감정의 꼬리)가 **0.380 = 뒤집으면 0.620**.
**우울할수록 부정감정의 꼬리가 얇습니다.** 최악의 순간이 튀는 게 아니라 전반적으로 고르게 부정적 —
**blunted affect(정서 둔마)**와 합치합니다. 화자 평균 방식으로는 안 잡히던 양입니다.

**Q. "왜 whisper-SER은 안 됐나?"**
→ dev 0.449(찍기 이하)인데 test만 0.636입니다. **두 평가셋이 정반대면 신호가 아니라 잡음**이라 통과로 읽지 않았습니다.
학습 데이터가 RAVDESS/SAVEE/TESS/URDU 합계 약 4,170개의 **연기(acted) 클립**이라 자연 인터뷰와 도메인 갭이 큽니다.

**Q. "MSP-Podcast 모델이 제일 좋다던데?"**
→ 도메인은 가장 가까웠지만 **Open RAIL 라이선스가 "clinical or diagnostic applications"를 명시적으로 금지**해서 제외했습니다.
Emotion2Vec-S는 Apache 2.0이라 사용 가능합니다.

**Q. "현행 persona 코드는 봤나?"** ← **역질문 필요**
→ 못 봤습니다. **0902 문서의 "그 외 간단한 개인정보"가 정확히 무엇인지** 확인이 필요합니다.
제안 스키마의 블록 B·C와 겹칠 수 있습니다.

## 6. 먼저 자백할 것 (숨기지 말 것)

1. **평가 코드 버그를 한 건 발견해 정정했습니다.** 폴드별 예측 확률을 척도 보정 없이 합쳐
   AUC가 0.08~0.12 깎이고 있었습니다(응답 지연 0.557 → **0.634**).
   이 버그로 **한 번 잘못된 결론(+0.142, "처음으로 잡음을 넘었다")을 냈다가 뒤집었습니다.**
   보고서 수치는 전부 수정 후 값입니다.
2. **0821 lat의 dev 값을 재현하지 못했습니다.** test는 0.773 vs 0.776으로 맞는데
   dev는 0.627 vs 0.678로 벗어납니다. 원인 미확인 → §4의 5번 안건.
3. **cv189는 보조 지표입니다.** 공식 split을 벗어나므로 0821 표나 논문 수치와 직접 비교 불가.
   공식 split 수치는 그대로 유지했습니다.
4. **감정 분포가 쏠려 있습니다.** sad 0.47 / happy 0.21 / neutral 0.20 — 여기서 "부정감정"은
   **사실상 sad 확률 하나**입니다. 조용한 인터뷰 말투를 모델이 sad로 읽는 도메인 편향일 수 있습니다.
5. **Emotion2Vec-S의 10토큰 평균은 우리 선택입니다.** 원설계는 오디오-LLM 입력.
   따라서 결론은 **"평균해서 쓰면 못하다"**이지 **"S가 열등하다"가 아닙니다.**
