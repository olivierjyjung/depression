# Persona 주입 특징 조사 (2026-09-15)

현행: PHQ-8 8항목 + demographics + 개인정보. 범위: 설계안까지 (API 키 필요한 지점 전).
근거: 논문 5편 + DAIC-WoZ 189세션 전수 분석. 재현 코드는 `persona/`.

## 결론

1. **PHQ-8 8항목 중 4개(Appetite·Tired·Concentrating·Moving)는 Ellie가 묻지 않는다.** 주입해도 대화에 나올 자리가 없다.
2. **대화를 분기시키는 사실(자녀·치료·진단·이주·군복무)이 persona에도 라벨에도 없다.** 이게 추가해야 할 것.
3. **고정 persona 집합은 안 맞는다.** 양성 42명이 30가지 증상 조합. train 107명 라벨 벡터를 골격으로 쓰는 게 낫다.
4. **척도는 PHQ-8 유지.** BDI-II로 세우면 DAIC 라벨과 달라 역채점 게이트를 못 건다.

## 1. DAIC에서 확인한 것

**Ellie 질문 인벤토리를 전사에서 직접 추출했다.** 363~492 세션은 Ellie 턴이 `슬러그ID (자연어)` 형식이라 질문 ID가 그대로 있다(`easy_sleep (how easy is it for you to get a good night's sleep)`). 300~362는 역매칭으로 흡수.

- 고유 슬러그 **163개 = 질문 87 + 백채널 76**, 커버 **186/189** 세션, 세션당 중앙값 62개
- 전 세션 공통 슬러그는 **7개뿐** → 고정 스크립트가 아니라 분기 대화
- **451·458·480은 Ellie 턴이 없다** (참가자 발화만). Ellie 턴 쓰는 파이프라인은 3개를 잃는다

**PHQ-8 대응.** 통로 있음: Sleep(`easy_sleep`,`sleep_affects`), Depressed(`feel_lately`), NoInterest·Failure(간접).
통로 없음: **Appetite·Tired·Concentrating·Moving** — 질문 87개에 대응이 없다.

**분기 발동률** (Ellie 턴 있는 186세션. 양성 56 / 대조 130):

| 분기 | 전체 | 양성 | 대조 |
|---|---:|---:|---:|
| 자녀 있음 | 31.7% | 44.6% | 26.2% |
| 치료 경험 | 40.3% | **75.0%** | **25.4%** |
| 진단 후속 | 64.5% | 83.9% | 56.2% |
| LA 이주 | 49.5% | 46.4% | 50.8% |
| 군 복무 | 3.8% | 3.6% | 3.8% |

**증상 개수** (항목 점수 ≥2를 "두드러짐"으로, train+dev 142명): 양성 42명의 중앙값 **5개**, 4개 이하는 **45.2%**, 고유 조합 **30가지**.

**발화 길이**: 세션 총량은 양성 1261 / 대조 1217로 차이 없음. 질문별로 방향이 갈린다 — 비교 가능한 99개 중 양성이 짧은 것 35개(긍정 회상: `happy_lasttime` −17, `situation_handled` −16), 긴 것 32개(자기평가·자유연상: `mind` +24, `Ellie17Dec2012_07` +14).

## 2. 문헌

| 축 | 현행 | TalkDep | PsyGAT | PATIENT-Ψ | Kang |
|---|---|---|---|---|---|
| 척도 | PHQ-8 8항목 | BDI-II + 핵심증상 ≤4 | TalkDep 상속 | CBT 인지구조 | PHQ-8 총점 난수 |
| 생애사·맥락 | ❌ | ✅ | ✅ | ✅ | ➖ |
| 발화 스타일 | ❌ | ✅ | ➖ | ✅ 6종 | ❌ |
| 예시 문답(ICL) | ❌ | ✅ | ✅ | ✅ | ➖ |
| 검증 게이트 | ❌ | ✅ 역채점 | ✅ 사람 검수 | ✅ 임상가 | ➖ |
| 개수 | 화자별 | 12 고정 | 4~12 → 992세션 | 106 | 화자별 |

- **TalkDep** (2508.04248): 8속성군. 핵심증상 **최대 4개** 제한 — DAIC 양성의 45.2%만 해당해서 그대로는 못 쓴다. 게이트는 등급일치 + |BDI차|<5.
- **PsyGAT** (2604.24126): DAIC에 992세션 합성, **train에만** 투입. 원본만 ~63 F1 → 증강 ~83 F1.
- **PATIENT-Ψ** (2405.19660): 척도 대신 CBT 인지개념화도 8필드 + **대화 스타일 6종**(plain/upset/verbose/reserved/tangent/pleasing)을 직교 축으로.
- **PSI-Bench** (2604.25840): 시뮬레이터 실패 4종 — 조기 감정해소, 부정→긍정 단조 궤적, **과도한 장황함**(64~319단어 vs 실제 18), 집단 다양성 부족.
- **Kang 2024** (2411.17672): DAIC 직접. 전사 전체 생성이 "끊김·반복·주제이탈"로 실패해서 요약본 생성으로 선회. 조건은 PHQ-8 총점 하나뿐.

## 3. 제안 스키마

| 블록 | 필드 | 출처 |
|---|---|---|
| A 증상 | `phq8_items`(8), `expressible_items`(Sleep·Depressed·NoInterest·Failure **4개만 발화 지시**), `salience` | train 107명 라벨 벡터 |
| B 분기 | `has_children`, `therapy_history`, `diagnosis_history`, `is_transplant`, `military` | §1 prior로 샘플링 |
| C 전기 | hometown, 학력, 직업, dream job, 가족 구성·친밀도, 거주, 취미, 여행 | LLM 생성 (B와 무모순) |
| D 일화 | 최근 다툼 / 행복했던 때 / 어려운 결정 / 후회 / 지우고 싶은 기억 / 자랑 / 죄책감 등 11개 | LLM 생성, 세션 전 고정 |
| E 스타일 | `style` 6종, `length_profile`(주제군별 목표 길이) | PATIENT-Ψ + §1 실측 |

A와 E는 직교. 같은 PHQ-8 벡터에 스타일을 바꿔 얹어 증강 배수를 만든다.

**게이트**: G1 LLM 역채점(이진 일치 + 총점차 ≤5) / G2 블록 B와 실제 질문 블록 일치 / G3 길이 분포가 실측 범위 / G4 서사 무모순 / G5 어휘 다양성(MTLD). G1·G3·G5 자동, G2 규칙, G4만 사람.

## 4. 확인 필요

1. **분기-라벨 상관을 재현할지.** 치료 경험이 양성 75.0% vs 대조 25.4%. 재현하면 분류기가 증상 아닌 분기 존재를 학습할 수 있고, 독립 샘플링하면 실제 양성 세션의 단서가 빠진다.
2. **BDI-II 대신 PHQ-8.** 역채점 게이트를 걸려면 DAIC 라벨과 척도가 같아야 한다.
3. **현행 persona의 "그 외 개인정보"가 무엇인지.** 블록 B·C와 겹치는지 확인 필요. 코드가 이쪽에 없다.
4. **451·458·480 처리.** Ellie 턴 없는 세션.
