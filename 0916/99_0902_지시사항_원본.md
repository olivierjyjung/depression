## Depression detection 정리

### 용어정리
- zero-shot : llm 을 prompt 만을 통해서 평가를 하는것.
- RAG : Retrieval-Augmented Generation, 대형 언어 모델(LLM)이 응답을 만들기 전에 외부 데이터베이스나 문서 등에서 필요한 정보를 먼저 검색하고, 이를 바탕으로 정확한 답변을 생성하는 AI 기술을 총칭,
        RED 페이퍼를 예로들면, Daic-woz 발화에서 발화를 text-embedding 벡터로 변환하고 이 벡터와 유사도가 높은것을 RED KB 에서 찾아 가져옴 (검색) 이를 RAG 라고 봄
- KB : knowledge base, RAG 방식을 통해서 가져오는 데이터 베이스를 말함
- LoRA : Low-rank adaptor, peft ( parameter effeicient fine-tuning) 의 방식으로 llm 의 파라메터 전체를 학습하는거가 비효율적이기 때문에 나온 방식. 대부분의 llm 튜닝은 이방식으로 한다고 봐도 무방.
- Persona : llm 분야에서는 주로 llm 에 주입해주는 "성격·말투·행동 규칙” 등을 말하며 prompt 로 넣어서 원하는 발화스타일을 제어함.


### 현재까지의 상황
- daic-woz 데이터셋을 통해 학습을진행
- 초기실험
    - 초기 llm zero-shot 을 통해서 어느정도까지 학습없이 llm 의 파워만으로 되는지 확인
    - 이후 daic-woz 에서 필요한 발화들을 필터링해서 그거를 사용하는 방식등을 고료
    - RED paper 의 재현을 통해서 학습없이 평가하는 것을 좀더 탐구해보았음

- RED 재현및 RAG 관련 실험 
    - COKE kb 를 통해서 대화에 맞는 tagging 을 하고 그 tagging 데이터와 함께 llm zero-shot 을 하는 스타일로 접근
    - kb 가 아닌 tagging 하는 것 자체를 llm zero-shot 으로 얻는 방식도 해봤음

- 학습 기반 실험
    - LLM LoRA 튜닝을 통해 학습 based 의 성능을 보고자했지만, daic-woz 데이터 자체의 발화수 적음, 화자의 전체발화가 아닌 문장별로 학습했을때 성능이 안나옴 등의 이슈로 성능이나오지 안흥ㅁ
    - Speech encoder, 그리고 다른 speech feature 들을 추가하여 dementia paper 스타일로 접근을 해보았지만 역시 성능이 좋지않고, 데이터 수 부족이 큰 약점이라는 결론

- 한계점들 
    - llm zero shot 만해도 성능이 높고, 이를 더 성능을 높히기위한 위의 실험들이 결국 RED 페이퍼에서 크게 벗어나지 못해서 다른방식을 찾아야했음
    - 학습스타일이 전무한것도 페이퍼를 쓰기에 좀 어려운 부분



### 개선하고자 하는 방향
- e-daic-woz
    - extended 버전이어서 화자가 더 많아짐.
    - 단점은 true-text 가 없다는점, 그리고 주어진 text 는 google asr 을 통해서 얻은 asr 결과물들
    - 마이크를 가지고 asr 을 돌렸기때문에 원 발화를 들어보면 participant 의 말은 크고 ellie 의 말은 작음. 그러다보니 asr 결과가 대부분 participant 만 들어가있음
    - 거기에 아주 가끔 인식되는 ellie 의 발화도 text 만 봤을대 구분이 안되어있음.

- Augmentaion
    - 발화 수, 화자 수 자체를 늘리고자함
    - 현재는 persona 에 주입하는것은 phq-8, demographics, 그외에 간단한 개인정보를 넣어 화자에대한 다양성을 줌.
    - Ellie 의 경우 분석결과 100여개의 고정된 질문을 하고, 대화의 흐름이 정해져있다는것을 알게되어 그런 흐름에 따라 주어진 발화를 대답하는 스타일로 만듬
    - 최종적으로 2개의 llm ( participant llm <-> Ellie llm ) 이 서로 대화하는 스타일로 대화를 augmentation 함 
    - 이러한 방식으로 daic-woz 의 데이터셋을 증강할수 있음.

- Speech emotion recognition
    - speech 모달리티를 사용하고싶지만 역시 기존의 speech embedding, 다른 speech feature 들로 한계가 있었음.
    - speech emotion recognition 용으로 학습한 speech model 을 가지고 depression detection 에 사용하면 괜찮은 성능을 낸다는 페이퍼 몇편 존재
        - 자세히 말하면, speech emotion recogntion task 용으로 학습한 모델의 embedding ( 마지막 분류 layer 전) 을 가져와서 쓰는 형태인거 같음.
        - speech emotion recognition task 를 모델이 학습하면 내부적으로 감정관련 embedding 을 얻을것이고 우리가 기존에 쓰던 speech model 들은 ASR 용이라 이거에비해 depression 에 더 좋은 embedding 으로 학습되었을것이라는 추론 가능
    - 다만 이것을 우리가 새로 학습하는것은 비효율적이라 open-source 로 나와있는 emotion recognition 모델들 찾아보고 이거의 성능평가, 그리고 daic-woz 대화셋에 적용해보는것 필요함


- 위의 내용 빼고 수요일에 나온얘기들 몇개
    - 일단은 daic-woz 로 돌아가서 이거를 성능높이는거로 한다.
    - llm zero-shot 에서 ellie turn 없이 평가하면 성능이 저하됨.
        - e-diac-woz 에서 소실된 ellie turn 을 복원하는걸 통해서 augment 하는것도 좋은듯?

## 관련 페이퍼 몇개
- TalkDep — arxiv.org/abs/2508.04248 — 임상의 루프로 BDI-II 기반 우울 환자 페르소나 12개를 만들고, LLM 역채점 게이트로 검증한 시뮬레이터 리소스.
- PsyGAT — arxiv.org/abs/2604.24126 — TalkDep 페르소나로 DAIC-WOZ 992세션을 합성 증강하고 GATv2로 학습, macro F1 89.99 달성.
- LSSED — arxiv.org/abs/2102.01754 — 대규모 SER 데이터셋(820명, 200h+)으로 사전학습한 모델을 DAIC-WOZ에 전이해, SER 사전학습이 ASR보다 우수함을 입증
